# まるばつ MaruBatsu

超シンプルなまるばつ（三目並べ）アプリ。2人で交互にタップして遊ぶ。

## 土壇場ルール（枠の一個外）

- 上段の右に、枠の一個外のマスが1つある（点線のオレンジ枠）。
- 普段はロックされていて置けない。
- 土壇場で解放される:
  - 盤の空きが2マス以下になったとき
  - 相手がリーチ（あと1手で3つ並ぶ）になったとき
- 解放中、その手番のプレイヤーが1回だけ置ける（1手として数える）。
- 枠外を使った勝ち筋:
  - 枠外 - 上段まん中 - 上段右
  - 枠外 - 中段右 - 下段まん中
- 盤が全部埋まっても枠外が残っていれば、最後の1手として枠外に置ける。

## ビルド

GitHub Actions（`.github/workflows/build-marubatsu.yml`）が macOS ランナーで
署名なし .ipa を作る。インストールには SideStore / AltStore での再署名が必要。
