# データモッシュ MoshCam

異なる2本の動画を、データモッシュ特有の「前の映像が次の映像の動きで溶けて崩れる」トランジションで繋げるiOSアプリ。

- bundle id: `com.kakuei.moshcam` / iOS 17以降 / バージョン 1.0
- 動画A（崩れる側）と動画B（滲み出る側）を写真から選択
- つなぎ目では、Bのフレーム間差分（動いた部分）だけがブロック状マスクとしてAの合成結果を置き換える。静止部分はAが残り、時間とともにリーク量が増えてBのクリーンな映像に着地する
- モッシュ長さ 0.3〜4.0秒、崩れの強さ、ブロックサイズを調整可能
- 音声はAの後ろにBをそのまま接続。出力はAのサイズ・向きに合わせ長辺最大1280pxのMP4
- 完成動画は写真へ保存・共有が可能

ビルドは GitHub Actions（`.github/workflows/build-moshcam.yml`）で未署名IPAを生成する。インストールには SideStore 等での再署名が必要。
